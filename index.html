WORK ORDER 01Ignition swap

Lead routing rebuilt from scratch, off a dying vendor

Came in with: A non-renewed LeanData contract. All lead routing and Gong deal alerts would go dark on a fixed date. Miss it, and every inbound lead sits with no spark.

Work performed: Documented the legacy logic, ran a parts evaluation (Salesforce Flow vs. Zapier), then designed, built, tested, and cut over both workflows, with driver training included.

Road test: Zero routing downtime through the cutover and a license off the books. Speed-to-lead, the number everything downstream depends on, never dipped.

Salesforce Flow · Zapier · Gong
WORK ORDER 02Self-driving mode

AI agents for the support-to-CRM pipeline

Came in with: Support and delivery data stranded in Zendesk and Asana, disconnected from CRM context, with bulk migrations done by hand, row by row.

Work performed: Built the Zendesk ↔ Salesforce connections, an SPR-to-MPR request workflow, and a Zapier agent that bulk-converts Asana projects into Zendesk tickets, then refactored the whole connection onto a cleaner V2 architecture.

Road test: The agentic pattern running in production: an AI-assisted worker doing a repetitive job a human used to do manually, and version two shipped before version one rusted.

Zapier agents · Zendesk · Asana
WORK ORDER 03Fuel injection

Account intelligence: revenue-driven lifecycle scoring

Came in with: Account lifecycle status (Prospect → Active → Customer → Former) and trailing revenue maintained by an offline Python script and hand-uploaded to the CRM. Stale fuel, every month.

Work performed: Automated monthly jobs that classify every account from Tableau revenue history and populate trailing-twelve-month revenue at the account level, natively in Salesforce.

Road test: Segmentation, territory, and outbound targeting now run on always-current signal instead of last month's manual upload.

Tableau · Apex scheduled jobs · SOQL
WORK ORDER 04Parts sourcing

Evaluating and consolidating the GTM tool stack

Came in with: A stack carrying unowned licenses of unclear value, while the team needed modern call recording, engagement, and enrichment parts.

Work performed: Structured evaluations across recording, engagement, and enrichment vendors, ran security review for new tools, audited legacy licenses for keep/drop decisions, and piloted the winners with stakeholder feedback loops.

Road test: The full build-vs-buy muscle GTM engineers are hired to own: sourcing, trialing, security, adoption, and scrapping parts that don't earn their line item.

Vendor evaluation · Security review · Change mgmt
WORK ORDER 05Drivetrain

Deal-to-delivery: automating the closed-won handoff

Came in with: Every closed deal required a manual handoff into Asana for delivery: slow, error-prone, fields re-typed by hand. Power made by sales was getting lost before it reached the wheels.

Work performed: An integration that auto-creates a fully field-mapped Asana project the moment an opportunity hits the right stage, extended with Zapier/Make for two-way updates.

Road test: A recurring manual process removed for the entire CS team, with stage changes as the single trigger of record.

Asana · Zapier · Make · Flows
WORK ORDER 06Engine rebuild

Fixing production Apex most GTM engineers can't touch

Came in with: An inherited Apex trigger framework knocking hard: blocking sellers on open deals with false errors and silently generating rogue renewal opportunities.

Work performed: Traced the full trigger execution path, isolated the faulty stage-gating logic, scoped a method-by-method remediation across every trigger context, and started migrating eligible automations to Flow.

Road test: This is the work you can't do from the driver's seat. When automation breaks at the code layer, I'm under the car, not waiting on an engineering sprint.

Apex · Triggers · Screen Flows
WORK ORDER 07Odometer & gauges

Making revenue schedules and ARR data trustworthy

Came in with: Revenue schedules calculating by day count instead of ACV/12, unreliable multi-year rollups, and churn data vanishing at Closed Lost. Every gauge on the dash was reading wrong.

Work performed: Rebuilt schedule generation with ACV/12 logic and mid-month handling, auto-generated step-up renewal opportunities, reworked renewal cloning, and enforced churn capture at Closed Lost.

Road test: Forecasts, comp, and board decks all read from these gauges. Now they read true.

Apex · Visualforce · Record Types · Flows
WORK ORDER 08Shop standards

CI/CD so GTM systems ship like software

Came in with: Salesforce changes deployed by hand. No source control, no review, no rollback, no maintenance history.

Work performed: A GitHub + Gearset pipeline for source-controlled, reviewable deployments across the full lifecycle, sandbox to production.

Road test: Every change logged like a service record. As GTM stacks absorb more automation and AI, this is how you go fast without blowing the engine everyone sells with.
